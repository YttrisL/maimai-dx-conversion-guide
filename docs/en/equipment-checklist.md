# ☑️ Purchase checklist

*Need details on where to buy, why, and alternatives? See the [full shopping list](equipment.md).*

## Mandatory hardware

- [ ] *ALLS HX2*
- [ ] 500 GB secondary hard drive (SUB STORAGE) - *if needed*
- [ ] Sega IO4 I/O board
- [ ] **1x**{: .quantity-emphasis } [maiConvert-IO4 conversion PCB]({{IO4_CONVERSION_PCB}})
- [ ] Aime reader (Gen. 3)
- [ ] **2x**{: .quantity-emphasis } HDX touchscreen
- [ ] **16x**{: .quantity-emphasis } HDX buttons
- [ ] **2x**{: .quantity-emphasis } OBSF-24TR button
- [ ] **1x**{: .quantity-emphasis } 4-port USB hub
- [ ] **1x**{: .quantity-emphasis } 5V/12V switching power supply

## Optional hardware (camera and QR-code)

- [ ] **1x**{: .quantity-emphasis } Player camera
- [ ] **2x**{: .quantity-emphasis } QR-code camera

# Complete Guide: The "DxNALE" Project

## Converting a maimai FiNALE cabinet into a maimai DX

Welcome to the detailed guide for the hardware conversion of a **maimai FiNALE** arcade cabinet to the **maimai DX** system. This document is based on [SpiralGlide's resources](spiralglide-resources.md) and has been expanded to be accessible even if you are not an electronics engineer.

---

## What is "DxNALE"?
DxNALE is the name the community gives to maimai FiNALE cabinets that have been converted to run maimai DX. The two systems are radically different, and it is strictly impossible to run DX on a FiNALE cabinet in its original state.

There is a persistent rumour within the community that converting a cabinet to DxNALE is a colossal, titanic, almost unachievable job. **That is not the case.** Some steps really are complex, but this guide is here to assist you through the whole operation.

!!! tip "The end goal: perfect software fidelity"
    It is possible to modify the game's data to make it compatible with any touchscreen produced by the community; however, what we are aiming for here is total software fidelity.

    **No software modification of the game is tolerated.** The game must "think" it is running on an original Sega cabinet. Every hardware adaptation we make must therefore be invisible to the game.

    The advantage of this approach is that the resulting DxNALE cabinet is, in theory, compatible with the philosophy of most of the major private servers for maimai DX.

## Where to start?

1. Read the [Warnings](warnings.md) to understand what the project involves and the consequences of the modification.
2. Check the [Shopping list](equipment.md); you need to obtain every item mentioned there.
3. Follow the conversion steps in order, starting with [Step 1: Central PC (ALLS)](step-1-alls-and-psu.md).

If some terms are unclear to you, feel free to consult the [Glossary](glossary.md). It covers every definition that might be obscure to a beginner.

Also, if you are not familiar with serial protocols, a from-scratch explainer sits in the appendices: "[Understanding serial protocols](understanding-serial-protocols.md)". They are a central part of this conversion.

**Congratulations in advance!** If you follow all of these steps, you will end up with a working, enhanced *maimai DxNALE* cabinet, ready for online play.

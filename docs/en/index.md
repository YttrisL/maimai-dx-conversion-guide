# Complete Guide: The "DxNALE" Project

## Converting a FiNALE cabinet into DX

Welcome to this detailed guide to **converting a FiNALE arcade cabinet into DX**. It builds on [SpiralGlide's resources](spiralglide-resources.md), expanded to stay accessible *even if you are not an electronics engineer*.

---

## What is "DxNALE"?

DxNALE is the name the community gives to FiNALE cabinets converted to run DX. The two systems are radically different: **DX cannot run on an original FiNALE cabinet.**

A persistent rumour says the conversion is a titanic, almost unachievable job. **That is not the case.** Some steps really are complex, but this guide walks you through the whole operation.

!!! tip "The goal: perfect software fidelity"
    It would be possible to modify the game's data to make it compatible with any hardware modification. This guide aims instead for total software fidelity.

    **No software modification of the game is tolerated.** The game must "think" it is running on an original cabinet: every hardware adaptation we make must therefore be invisible to it.

    The upside: the resulting cabinet is, in theory, compatible with the philosophy of most major private servers for DX.

**Congratulations in advance!** By following all of these steps, you will end up with a 100% working *DxNALE* cabinet, ready for online play.
